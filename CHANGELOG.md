# Changelog

This monorepo versions each package on its own, with [Changesets](https://github.com/changesets/changesets).
Release notes live in the package changelogs, generated by the "Version Packages" pull request:

- [`@oxpulse/chat-sdk`](packages/chat-sdk/CHANGELOG.md)
- [`@oxpulse/chat-widget`](packages/chat-widget/CHANGELOG.md)
- [`@oxpulse/crypto-primitives`](packages/crypto-primitives/CHANGELOG.md)
- [`@oxpulse/intro-protocol`](packages/intro-protocol/CHANGELOG.md)
- [`@oxpulse/url-contract`](packages/url-contract/CHANGELOG.md)
- [`@oxpulse/voice-core`](packages/voice-core/CHANGELOG.md)
- [`@oxpulse/wire-codec`](packages/wire-codec/CHANGELOG.md)

Each release is also a git tag named `<package>@<version>`. Repository-level changes that belong to
no package (CI, root documents, tooling) are not versioned and appear only in the git history.

## Unreleased

- `@oxpulse/intro-protocol`: verify the introduction AUTH signature with strict Ed25519
  (`zip215: false`); pending as a changeset in `.changeset/`. Versions up to and including 0.2.4
  accepted a small-order or non-canonical peer key with an identity-point signature.
