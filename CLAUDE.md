# CLAUDE.md

Notes for coding agents working in oxpulse-chat-sdk: a pnpm monorepo of TypeScript packages for
embeddable end-to-end-encrypted group chat (client SDK, widget, wire codec, crypto primitives, room
URL contract, voice core, introduction protocol). Every document is indexed in
[docs/INDEX.md](docs/INDEX.md).

## Layout

Packages are in `packages/` (`wire-codec`, `chat-sdk`, `chat-widget`, `crypto-primitives`,
`url-contract`, `voice-core`, `intro-protocol`); each has its own `README.md`, `LICENSE` and
generated `CHANGELOG.md`. `e2e/` holds the contract test, `scripts/` the release and manifest
guards, `docs/` the integration guides, architecture notes and ADRs.

## Gate

CI (`.github/workflows/preflight.yml`, job on `ubuntu-24.04-arm`, Node 24, pnpm) runs exactly:

```sh
pnpm install --frozen-lockfile
pnpm lint:manifests
pnpm build
pnpm --filter @oxpulse/chat-widget build:cdn
pnpm typecheck
pnpm test
```

Use Node 24: CI asserts `navigator.locks` (Web Locks) exists, because the replay-guard tests lose
coverage silently without it, even though the root `engines` field only says `>=22`.
`mutation.yml` runs Stryker nightly and never gates a merge. A docs-only PR (Markdown, `docs/`,
licence, issue and PR templates) skips the heavy job through the `docs-scope` job in
`preflight.yml`; that block is canonical across the fleet and compared byte for byte, so do not
edit it here.

## Invariants that are easy to break

- **The E2EE invariants checklist is binding.** Read
  [docs/architecture/e2ee-model.md](docs/architecture/e2ee-model.md) section 8 before touching
  decrypt, downgrade, poison-gate or replay code: serial unseal per room, `#cryptoMode` set once at
  construct, poison before throwing and per room never client-wide, `DurableReplayGuard.accept()`
  only after a successful AEAD unseal, and the three wire brands (`WireBytes`, `HttpWireBytes`,
  `SealedBytes`) never collapsed by an `as` cast.
- **Security-relevant changes need a test that fails without them.** Constant-time comparison,
  signature verification and key handling are covered by the ADRs in `docs/adr/`; follow them rather
  than re-deriving.
- **Every package change needs a changeset** (`pnpm changeset`), committed with the code. Versions
  and `CHANGELOG.md` files are generated by the "Version Packages" PR; never edit them or tag by
  hand. See [RELEASING.md](RELEASING.md).
- **Publishing is OIDC trusted publishing from `release.yml`.** No npm token exists anywhere; never
  add one. `scripts/assert-no-publishconfig-directory.mjs` forbids `publishConfig.directory`.
- **`pnpm-lock.yaml` is committed and installs are frozen.** The `@noble/*` versions are pinned
  through `overrides` in `pnpm-workspace.yaml`; change them deliberately.
- **The widget CDN bundle is self-contained and immutable per version** (`chat-sdk` inlined,
  versioned path). See [docs/embedding.md](docs/embedding.md); do not change a published path.
- **CSP-safe means no `eval` and no `Function` calls** in `chat-sdk` and `chat-widget`.
- **This repository is public.** No hostnames of operator infrastructure, no operator paths, account
  names, tokens or personal data in any tracked file, docs and runbooks included.
